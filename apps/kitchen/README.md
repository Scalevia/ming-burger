# Ming Burger — Kitchen display

Flutter app for the kitchen. Arabic (RTL) only in V1. Shared code lives in [`packages/shared`](../../packages/shared).

```bash
cp config/dev.example.json config/dev.json   # then set the publishable key
flutter run --dart-define-from-file=config/dev.json
```

Phase 1: foundation shell only. Production hardware is not decided; Android is used as the development target.
