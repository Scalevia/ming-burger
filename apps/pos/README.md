# Ming Burger — POS (cashier)

Flutter app for cashiers. Arabic (RTL) only in V1. Shared code lives in [`packages/shared`](../../packages/shared).

```bash
cp config/dev.example.json config/dev.json   # then set the publishable key
flutter run --dart-define-from-file=config/dev.json
```

Phase 1: foundation shell only. Production hardware (Android / Windows / iPad) is not decided;
Android is used as the development target.
